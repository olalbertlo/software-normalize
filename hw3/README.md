## 待測程式

輸入為完成的圈數（非負整數）。每圈得 1 點，每天最多採計兩圈，集滿兩圈再送 1 點。

```text
1  def walk_points(laps: int) -> int:
2      points = 0
3      for _ in range(min(laps, 2)):
4          points += 1
5      if points == 2:
6          points += 1
7      return points
```

用行號表示函式內的路徑。第 3 行判斷是否還有下一圈，第 4 行加點後回到第 3 行。下表的 `34` 表示邊 `3→4`，`343` 表示連續走過 `3→4→3`。

## 測試案例

| 案例 | Input values（圈數） | Expected result（點數） | Test program’s result（實際點數） | Criteria analysis（完整路徑、邊、邊對） |
| --- | ---: | ---: | ---: | --- |
| T1 | 0 | 0 | 0 | 路徑 `2→3→5→7`（不進入迴圈）。邊 `23,35,57`。邊對 `235,357`。 |
| T2 | 1 | 1 | 1 | 路徑 `2→3→4→3→5→7`（繞一圈）。邊 `23,34,43,35,57`。邊對 `234,343,435,357`。 |
| T3 | 4 | 3 | 3 | 路徑 `2→3→4→3→4→3→5→6→7`（繞兩圈並加獎勵）。邊 `23,34,43,35,56,67`。邊對 `234,343,434,435,356,567`。 |

## 結果

| 測試目標 | 最少案例 | 涵蓋率 | 為什麼需要這些案例 |
| --- | --- | --- | --- |
| Edge | T1、T3（2 例） | 7/7 = 100% | 第 5 行只判斷一次，要分兩次呼叫才能走到 `56` 和 `57`。 |
| Edge-Pair | T1、T3（2 例） | 8/8 = 100% | `235` 只在零圈出現，`434` 只在採計兩圈時出現，兩者必須分開測。 |
| Path | T1、T2、T3（3 例） | 3/3 = 100% | 迴圈只能執行 0、1、2 次。每種圈數各對應一條完整路徑，每次呼叫只走其中一條。 |

T1 涵蓋「沒繞過迴圈」的 1 條路徑。T2、T3 涵蓋「有繞過迴圈」的 2 條路徑。三項目標共用這 **3 個案例**。
